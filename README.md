# Dota Text Draw

Рисует текст на **миникарте Dota 2** движением мыши с зажатым `Ctrl+ЛКМ`
(как рисуют в игре), по контурам букв шрифта Arial.

## Установка

Нужен Python 3 (Windows). Зависимости:

```
py -m pip install -r requirements.txt
```

## Запуск

```
dota_text_draw.bat            # запуск в трее, без окна cmd
dota_text_draw.bat --console  # запуск с консолью (для отладки)
```

Двойной клик по `dota_text_draw.bat` запускает программу в фоне — в системном
трее появляется иконка (синий квадрат «D»). Окно cmd не открывается.
Повторный запуск не создаёт вторую копию.

## Как пользоваться

1. **Первый запуск** — программа предложит калибровку: зажми левую кнопку мыши
   и обведи миникарту прямоугольником, затем `Enter` (сохраняется в `config.json`).
   Перекалибровка в любой момент — кнопка в настройках (`Ctrl+Alt+C`) или трее.
2. В игре нажми `Ctrl+Alt+D` — появится маленький оверлей ввода.
3. Набери текст (до 10 символов), нажми `Enter` — мышь сама «напишет» его в центре
   миникарты. `Esc` — отмена.

## Хоткеи и трей

| Действие             | Клавиши по умолчанию |
|----------------------|----------------------|
| Оверлей ввода текста | `Ctrl+Alt+D`         |
| Настройки            | `Ctrl+Alt+C`         |

Хоткеи можно поменять под себя в настройках — нажми на кнопку с текущей
комбинацией и введи свою (минимум один модификатор: `Ctrl`/`Alt`/`Shift`).
Изменения применяются сразу.

В трее (правый клик по иконке): «Оверлей ввода», «Настройки», «Калибровка миникарты», «Справка», «Выход».

## Настройки (`Ctrl+Alt+C`)

- **Скорость рисования** — три пресета, сохраняется в `config.json`:

  | Пресет   | Описание                          | ~Время на «Привет» |
  |----------|-----------------------------------|--------------------|
  | Качество | Максимально чётко, медленно       | ~7-8 сек           |
  | Средняя  | Хороший баланс                    | ~4-5 сек           |
  | Быстрая  | Максимально быстро, чуть грубее   | ~2-3 сек           |

  При «Быстрой» прямые участки букв упрощаются и могут чуть рваться — если так,
  вернись к «Средней» или «Качеству».
- **Горячие клавиши** — переназначение хоткеев «Ввод текста» и «Настройки».
- **Калибровка миникарты** — переобвести прямоугольник миникарты заново.

## Проверка без игры

```
py dota_text_draw.py --selftest   # проверка конвертации текста в штрихи
py dota_text_draw.py --test       # мышь движется по траектории БЕЗ нажатий
```

> Запуск через `pythonw` (из .bat) не показывает `print` — всё пишется в
> `dota_text_draw.log` рядом со скриптом.

## Важно

- Dota должна работать в режиме **«Окно без рамки» (Borderless window)**, иначе
  оверлей свернёт игру при открытии.
- Позицию текста можно поправить повторной калибровкой (кнопка в настройках
  `Ctrl+Alt+C` или в трее): просто обведи миникарту прямоугольником в нужных границах.

## Конфигурация

Все пользовательские настройки хранятся в `config.json` (создаётся при первом
запуске; в репозиторий не входит, вместо него — `config.example.json`):

```json
{
  "minimap": { "left": 17, "top": 1067, "right": 379, "bottom": 1416 },
  "speed": "slow",
  "hotkeys": {
    "draw":     { "mods": ["control", "alt"], "key": "d" },
    "settings": { "mods": ["control", "alt"], "key": "c" }
  }
}
```

`speed` — `slow` / `medium` / `fast`. Модификаторы — `control`, `alt`, `shift`; `key` — буква, цифра, `f1`-`f12`, `space`, `tab`, стрелки и т.п.

## Тонкая настройка (константы в начале `dota_text_draw.py`)

| Константа              | Назначение                                    | По умолчанию |
|------------------------|-----------------------------------------------|--------------|
| `MAX_TEXT_WIDTH_FRAC`  | Доля ширины миникарты под текст               | `0.8`        |
| `STEP_PX`              | Шаг интерполяции точек мыши                   | `2.0`        |
| `STEP_DELAY`           | Пауза между точками, сек                      | `0.008`      |
| `PRESS_DELAY`          | Пауза после нажатия/отпускания ЛКМ, сек       | `0.08`       |
| `SIMPLIFY_EPS`         | Упрощение линий (0 = выключено)               | `0.0`        |
| `MAX_JUMP_PX`          | Макс. шаг между точками, чтобы не было разрывов | `8.0`      |
| `MAX_CHARS`            | Лимит длины текста                            | `10`         |

По умолчанию — максимальное качество (плотное рисование, ~5-8 сек на слово).
Если хочется быстрее и не страшно лёгких разрывов на прямых: поставь
`SIMPLIFY_EPS = 0.8` (станет ~2-3 сек) или уменьшь `STEP_DELAY` до `0.006`.

## Проблемы

- **Линии рвутся / текст неразборчив** — увеличь `STEP_DELAY` (например `0.01`)
  и `PRESS_DELAY` (`0.1`); убедись, что `SIMPLIFY_EPS = 0`.
- **Мышь не двигается в игре** — проверь, что Dota в borderless-режиме.
- **Хоткей не срабатывает** — комбинация занята другим приложением; смени её
  в настройках (`Ctrl+Alt+C`). Ошибки регистрации показываются в трее.
- **Буквы двойные («два кольца» у O/0/B)** — уже исправлено: программа рисует
  только внешний контур буквы (однослойно), внутренние дырки пропускаются.
  Точки у i/j/! остаются отдельными штрихами.
